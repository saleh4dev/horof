# حروف

مسابقة كلمات عربية تعمل على الإنترنت (PHP + MySQL).

القائد ينشئ غرفة، يظهر باركود ورابط المشاركة، والمتسابقون يكوّنون كلمات من أحرف عشوائية.

## النشر على Render

1. أنشئ قاعدة **MySQL** من Render (Private Service) وانتظر حتى تصبح Live.
2. من [New Web Service](https://dashboard.render.com/web/new) اختر هذا المستودع.
3. Runtime: **Docker**
4. أضف نفس قيم ملف `.env.example` في **Environment**:

```
DB_HOST=اسم-خدمة-mysql-الداخلية
DB_PORT=3306
DB_NAME=horof
DB_USER=...
DB_PASSWORD=...
```

على Render يمكن ترك `APP_URL` فارغاً؛ التطبيق يستخدم `RENDER_EXTERNAL_URL` تلقائياً.

الجداول تُنشأ تلقائياً عند الإقلاع.

## ملف البيئة

بيانات الاتصال تُقرأ من المتغيرات البيئية أو من ملف `.env`:

```
DB_HOST=localhost
DB_PORT=3306
DB_NAME=horof
DB_USER=
DB_PASSWORD=
APP_URL=
```

لا ترفع ملف `.env` الحقيقي إلى GitHub. انسخ `.env.example` فقط.

## الاستخدام

- **القائد:** ينشئ الغرفة ويحدد عدد الجولات ومدة كل جولة، ويظهر له الباركود ورابط المشاركة. يمكنه طرد لاعب أو إنهاء الجولة أو إنهاء المسابقة.
- **المتسابق:** يمسح الباركود أو يفتح الرابط ويكتب اسمه.
- **شاشة العرض:** من زر «شاشة العرض» على الكمبيوتر أو التلفاز.

الجولة تنتهي بانتهاء الوقت أو بإنهاء القائد، ثم تُعرض النتائج مع المجموع، وتبدأ التالية تلقائياً.
